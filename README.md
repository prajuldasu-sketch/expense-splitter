💰 Group Expense Splitter

A simple, user-friendly web application designed to manage shared expenses and split bills among friends, classmates, roommates, and groups.

The Group Expense Splitter makes it easy to track group spending, calculate individual shares, and understand who owes whom — helping everyone manage shared expenses transparently.

🚀 Features

- Add Expenses: Easily record expenses with descriptions and amounts.
- Group Expense Management: Manage shared expenses among multiple members.
- Expense Splitting: Divide expenses among group members.
- Balance Calculation: Automatically calculate individual contributions and balances.
- Who Owes Whom: Identify who needs to pay and who should receive money.
- Expense History: Keep track of recorded group expenses.
- Simple Interface: Clean and user-friendly dashboard.
- Responsive Design: Works across desktop, tablet, and mobile devices.

⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the "index.html" file.
4. Run it using the Live Server extension or your browser.
5. Start managing and splitting group expenses!

🎯 Project Objective

The main objective of this project is to simplify shared expense management by providing an easy way to record expenses, divide bills, calculate balances, and maintain transparency among group members.
